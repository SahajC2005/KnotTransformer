Step 1 — Points become tokens

Each of 6 data points gets described by 6 local features, then projected into a 64-dimensional vector.

Each column is one point. The 6 features capture position, distances, turning angle, and sequence position.

Why 6 features?

Raw (x,y) alone doesn't tell the model if a point is at a sharp bend or a gentle curve. The distances and turning angle add local geometric context. The position k/N adds global ordering.

Step 2 — Encoder: points look at each other

3 layers of self-attention. Click any point in the top row to see which other points it attends to.

Click a point to change the attention source. Line thickness = attention weight.

Q·KT (similarity)
Every pair of points gets a score: "how relevant is point j to point i?" Softmax turns scores into weights summing to 1.
Weighted sum of V
Each point's new vector = weighted average of all points' values. After 3 layers, each point "knows about" every other point.
Q = H·WQ, K = H·WK, V = H·WV
Attn = softmax(QKT / √dk) · V   // dk = 64/4 = 16 per head, 4 heads total

What the encoder learns

Linear probes on the encoder output recover: chord fraction (R²=0.98), turning angle (R²=0.82), curvature (R²=0.76). The model computes these through attention — no formulas for them exist in the code.

Step 3 — Decoder: queries extract knots

Learned query vectors cross-attend to the encoded points. Each query becomes one knot. Click a query to see its attention pattern.

Click a query (amber) to see which encoded points (green) it attends to.

Self-attention among queries
Queries coordinate: "You cover the first third, I'll handle the middle." Prevents knots from bunching up.
Cross-attention to encoder
Each query looks at encoded points: "What geometry do I need?" Query for the middle attends to the sharpest-turn region.

Why DETR-style queries?

The model needs to output K = N−2 knots, which varies with N. The 7 learned queries (Kmax+1) give a fixed maximum; a mask selects which ones are active for each sample. For N=6: 5 active (4 knots + 1 slack).

Step 4 — Knot head: scores → ordered knots

Drag the raw scores to see how softplus → cumsum → normalize produces valid ordered knots.

A: si = softplus(ri) + ε  // strictly positive increments
B: ci = Σj≤i sj  // cumsum → automatically increasing
C: ui = ci / cK+1  // normalize → all in (0, 1)
Always valid by construction: softplus > 0 → cumsum is increasing → division maps to (0,1). No sorting needed. The ordering is guaranteed mathematically, not enforced by a constraint.

Step 5 — The full chain

Everything connects. Forward pass computes the curve; backward pass teaches the attention layers.

Forward: points → encoder (self-attn ×3) → decoder (cross-attn ×3) → knot head → knots → solve A(u)P=D̃ → curve → energy E

Backward: ∂E/∂θ = ∂E/∂u · ∂u/∂θ
  ∂u/∂θ = standard backprop through transformer
  ∂E/∂u needs: ∂P/∂uk = −A−1(∂A/∂uk)P  // implicit differentiation through the solve
Implicit differentiation
When knot uk changes, A changes, so P must adjust to keep AP = D̃. The formula gives exactly how much P moves per unit change in uk.
Self-supervised
The loss is just E — the curvature of the curve. No labels. The curve grades itself. Every step is differentiable, so gradients flow all the way back.
